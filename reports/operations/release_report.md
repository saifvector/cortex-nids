## 🚀 Semantic Versioning Standard

The project adheres to Semantic Versioning (`MAJOR.MINOR.PATCH`):
- **MAJOR**: Breaking API schema changes or core architectural rewrites.
- **MINOR**: Backward-compatible feature additions, new ML models, or new SIEM/SOAR connectors.
- **PATCH**: Backward-compatible bug fixes and security hotfixes.

## 📄 Release Assets & Documentation Packages

Every official release incorporates the following artifacts:
- Source code tarballs (`.tar.gz` and `.zip`).
- `Project_Report.pdf`: Executive ML evaluation report.
- `Architecture.pdf`: Technical topography specification.
- `Installation.pdf`: Operational setup guide.
- `test_report.md` & `performance_report.md`: QA and SLA benchmark summaries.
