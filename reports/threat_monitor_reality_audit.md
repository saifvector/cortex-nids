## 🛠️ Code Modifications & Diffs

### 1. `frontend/src/pages/ThreatMonitor.tsx`
- **Removed**: `INITIAL_EVENTS` (`EVT-1001` - `EVT-1005`), `ATTACK_POOL`, and `fallbackTimer`.
- **Added**: `fetchInitialAlerts()` invoking `apiService.getAlerts()` on mount.
- **Added**: Dynamic WebSocket event mapper connecting to `ws://localhost:8000/ws/alerts`.
- **Added**: 3-second REST fallback polling against SQLite `alerts.db`.

### 2. `src/alert_engine.py`
- Added `get_max_rowid()`: Returns `COALESCE(MAX(rowid), 0)` from `alerts` table.
- Added `get_alerts_after_rowid(last_rowid, limit=50)`: Fetches new alerts inserted after `last_rowid` ordered by `rowid ASC`.

### 3. `api/routes.py`
- Updated `/ws/alerts` WebSocket endpoint:
  ```python
  @router.websocket("/ws/alerts")
  async def websocket_alerts_endpoint(websocket: WebSocket):
      await ws_manager.connect(websocket)
      last_rowid = alert_engine.get_max_rowid()
      try:
          while True:
              await asyncio.sleep(1.0)
              new_alerts, max_rowid = alert_engine.get_alerts_after_rowid(last_rowid=last_rowid, limit=50)
              if new_alerts:
                  last_rowid = max_rowid
                  for alt in new_alerts:
                      await websocket.send_json(alt)
      except WebSocketDisconnect:
          ws_manager.disconnect(websocket)
  ```
